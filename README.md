# 📔 Дневник (Daily Note)

Веб-приложение для ведения личного дневника с поддержкой вложений, напоминаний на Email и рисования прямо в браузере.

## 📖 О проекте

«Дневник» — это удобное и минималистичное веб-приложение, которое позволяет пользователю структурировать свои мысли, планы и события. 

### Основные возможности:
- **Папки и подпапки:** Создание древовидной структуры дневников для организации записей (например: «Ежедневник» -> «Октябрь» -> «Неделя 1»).
- **Записи:** Создание, редактирование и удаление записей с указанием даты, заголовка, текста и тегов.
- **Вложения:** Возможность прикреплять к записям фотографии, видео и документы (PDF, DOCX и т.д.).
- **Рисование:** Встроенный холст (как в Paint) для создания зарисовок прямо в форме записи. Есть ластик, выбор цвета и толщины кисти.
- **Напоминания на Email:** Указание даты и времени, после которого на почту пользователя автоматически приходит письмо с текстом записи (работает через Celery и Redis).
- **Поиск и фильтрация:** Поиск по слову, тегу и диапазону дат.
- **Красивый интерфейс:** Адаптивный дизайн в акварельных серо-мятных тонах с использованием шрифтов `Comfortaa` и `Marck Script`.

## 🛠 Стек технологий

- **Python 3.12**
- **Django 6.0**
- **Celery** (для асинхронной отправки email)
- **Redis** (как брокер сообщений для Celery)
- **Bootstrap 5.3** (базовая сетка и компоненты)
- **HTML5 Canvas** (для рисования)
- **SQLite / PostgreSQL** (база данных)
- **Coverage** (для измерения покрытия тестами)
